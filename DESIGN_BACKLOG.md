# Дизайн-система SHIFT — бэклог расхождений с макетами

Источник макетов: OpenDesign-проект «SHIFT Weather Design System»,
`weather-app-prototype.html` (SunWeather, DS v0.2, Material 3).

## Функциональность из макетов, которой нет в приложении

1. **Живой поиск по городам** (M3 SearchBar «Найти город…»): фильтрация по
   имени / штату / стране + состояние «Ничего не найдено».
   Сейчас нет инфраструктуры фильтрации: список городов — Paging 3 из Room.
   Нужен `LIKE`-запрос в `CitiesDao`, состояние запроса в `CitiesComponent`
   и перезапуск пейджинга. Поиск не показан, чтобы не рисовать мёртвое поле.

2. **Снекбар с «Отменить»** при переключении звезды избранного.
   Нужен канал одноразовых UI-событий из `CitiesComponent` + хранение
   последнего переключённого города для undo.

3. **«Вероятность осадков сегодня»** на экране погоды.
   В модели `WeatherContainer` нет поля вероятности; OpenWeather current
   weather API её не отдаёт — нужен доп. источник/запрос.

4. **«Снег за 24 часа»** — модель хранит осадки только за 1 ч / 3 ч
   (показаны фактические интервалы, не как в макете).

5. **Состояние ошибки сети на экране стран** (wifi_off + «Повторить»).
   `CountriesComponent` не различает ошибку и пустой список — при сбое
   загрузки экран остаётся в состоянии «загрузка». Нужна модель состояния
   Loading / Error / Content + retry.

6. **Название города в шапке погоды при GPS-запуске** (`cityId == null`):
   город неизвестен, показан fallback «Current location». Поиск ближайшего
   города по координатам — отдельная задача.

## Расхождения, требующие продуктового решения

7. **Экран Favorites** есть в приложении, но отсутствует в макетах
   (там избранное — только звёзды в списке городов). Сейчас экран сохранён,
   пункт в drawer оставлен (решение от 27.10.2026). Позднее: оставить или
   перейти на модель «только звёзды».

8. **Пункт Settings** удалён из drawer (был заглушкой), в макетах его нет.
   Если настройки нужны — проектировать отдельно.

9. **Roboto Mono** (моноширинные числа и подписи-ключи в макете) не подключён —
   используется Roboto. Решить: добавлять ли шрифт как ассет
   (сейчас различие чисто типографическое).

10. **Часовой пояс**: «Обновлено в …» показывается по времени устройства;
    у `WeatherContainer` есть `timeZone` — при необходимости показывать
    время города.

11. **Демо-подпись drawer** («Демо-модель данных v1») не переносилась —
    артефакт прототипа.
